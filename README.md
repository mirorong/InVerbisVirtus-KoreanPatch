# In Verbis Virtus 비공식 한글패치

스팀판 **In Verbis Virtus**(인 버비스 버투스) 비공식 한글패치입니다.

> 📖 **설치 방법, 스크린샷, 업데이트 소식은 블로그에서 확인하세요**
> 👉 https://mirorong0323.tistory.com

## 다운로드

[**최신 버전 받기**](https://github.com/mirorong/InVerbisVirtus-KoreanPatch/releases/latest)

Releases 페이지의 **Assets**에서 패치 zip 파일을 받으시면 됩니다.
함께 표시되는 Source code 파일은 받을 필요 없습니다.

## 설치 방법

1. Steam 라이브러리에서 게임 우클릭 → **관리 → 로컬 파일 보기**로 게임 폴더를 엽니다.
2. zip 안의 **`UDKGame` 폴더와 `Binaries` 폴더**를 게임 폴더에 그대로 복사합니다. (덮어쓰기)
3. 게임을 실행하면 바로 한국어로 나옵니다. 언어를 따로 바꿀 필요는 없습니다.

## 패치 지우기

Steam 라이브러리에서 게임 우클릭 → **속성 → 설치된 파일 → 게임 파일 무결성 확인**을 누르면 영어 원본으로 돌아갑니다.

## 알아두세요

- 한국어는 **영어(English) 자리**에 들어갑니다. Steam에서 게임 언어가 English로 되어 있어야 하며, 다른 언어로 되어 있으면 한국어가 나오지 않을 수 있습니다.
- 메뉴·일지·힌트·자막 등 게임 속 글과, 글자가 그려진 그림(타이틀 로고, 인트로, 벽 낙서, 엔딩 크레딧)을 한국어로 옮겼습니다. 로딩 화면의 제목과 크레딧의 사람 이름은 원래대로 둡니다.
- 주문은 게임 설정의 **주문 언어**(마하키 / 영어)에 따라 원래 발음 그대로 외웁니다. 한국어로 외우는 주문은 없습니다.
- 마이크 설정에서 한국어 장치 이름이 깨져 보이던 원래 게임의 문제도 함께 고쳤습니다. 그래서 zip에 `Binaries` 폴더가 들어 있습니다.
- 세이브·프로필 이름은 원래 게임처럼 영문과 숫자만 입력할 수 있습니다.
- 스팀판 최신 버전(1.0.2407) 기준입니다. 게임이 업데이트되면 한글이 나오지 않거나 게임이 제대로 실행되지 않을 수 있습니다. 이때는 '패치 지우기'로 원본을 되돌리고 패치 업데이트를 기다려 주세요.
- 설치 전에 세이브 파일을 백업해 두길 권장합니다. (세이브 위치: 게임 폴더의 `Binaries\Win32\UserCode\Saves`)
